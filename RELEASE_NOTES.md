# DialDuo Release Notes

## v2.0.1

### Highlights
- **Main Menu Refresh**: Added full-width **All Settings** above Exit, renamed **Call Scheduler**, removed the redundant Accounts grid tile, and added quick shortcuts for **Theme**, **Call Style**, and **Dialer Style**.
- **Call Scheduler Polish**: Fixed the Exact Alarm permission banner so it updates immediately after enabling permission, and updated contact selection to **Select Contact** with inline permission prompt when needed.
- **Call History & Statistics**: Added universal and per-contact call statistics charts, all-time missed/incoming/outgoing call filters, Contact Details navigation from the history modal header, and an expandable Call History section inside Contact Details.

## v2.0.0

### Highlights
- **DialDuo Rebrand & Logo**: New adaptive launcher icon and two-tone **DialDuo** wordmark across the app.
- **Redesigned Contacts Tab**: Clean contact rows showing avatar, name, and dial button, with inline card expansion for multi-number contacts.
- **Dedicated Contact Details Screen**: Full contact view with photo, labeled phone numbers, copy/dialpad/SMS actions, auto-detected third-party calling apps (WhatsApp, Telegram, Google Meet, etc.), system Contacts editor integration, and confirmed in-app deletion.
- **Instant Contact Sync**: Real-time contact provider observer and foreground resume sync so newly added or edited contacts appear right away.
- **SMS, Call History & Statistics**: Send SMS from Contact Details, long-press history menu, or the single-line history modal bar; inspect all-time missed/incoming/outgoing calls, tap modal headers to jump to Contact Details, view per-contact call history, and open universal or per-contact call statistics charts.
- **In-App APK Updates**: Download and install signed GitHub release APKs directly from the update prompt or Settings.
- **SIM Call Proximity & Permissions**: Fixed proximity sensor wake lock during SIM calls, removed unnecessary restricted permission prompts on launch, and added an interactive live dialer preview in Dialpad Style settings.
